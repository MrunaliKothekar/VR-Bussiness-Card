# VR-Business-Card

An Android-based Augmented Reality (AR) application for creating and accessing virtual business cards in an interactive and immersive way.

## 📱 Overview

VR-Business-Card is an AR-powered Android application that allows users to display and interact with digital business cards using augmented reality technology. The project demonstrates the integration of AR features into mobile applications to provide a modern and engaging networking experience.

---

## ✨ Features

* 📇 Virtual business card visualization
* 📱 Android application built using Android Studio
* 🎨 Interactive and user-friendly UI
* ⚡ Real-time AR rendering
* 🔗 Modern digital networking concept

---

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Android Studio
* Java JDK
* Android SDK
* ARCore supported Android device

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/MrunaliKothekar/VR-Bussiness-Card.git
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Run the application on a physical Android device

---

## ▶️ Running the App

Connect an Android device and click:

```text
Run ▶
```

inside Android Studio.
